# Git Practice

## Interesting Article

[Things You Should Never Do, Part I](https://www.joelonsoftware.com/2000/04/06/things-you-should-never-do-part-i/) by Joel Spolsky

## Why I Find It Interesting

In this article, Joel Spolsky argues that the worst strategic mistake a software company can make is deciding to rewrite its code from scratch. He uses Netscape as an example: the company threw away its working browser code to start over, and it spent years without releasing a major new version while competitors moved ahead. What caught my attention is his point that programmers often think old code is a mess simply because it is harder to read code than to write it.

What I learned is that old code is valuable because it holds years of bug fixes and lessons learned from real users. Many of the strange-looking lines in an old codebase exist to handle problems that someone already discovered and solved. Rewriting everything throws that knowledge away. For software developers, the lesson is to improve existing code step by step through refactoring instead of starting over.
